What Is MongoDB

MongoDB stores JSON-like documents in collections instead of rows in tables. Mongoose is the package that adds schemas, which set the shape and rules of each document. A model is a schema you can run queries on. The .env file for MongoDB is on the Setup page.

Project Setup

Install the package

Run this from the folder that has your server package.json.

npm install mongoose

Atlas steps

  • Create a free cluster at cloud.mongodb.com.
  • Under Database Access, add a user with the readWrite role on only your project's database, not Atlas admin.
  • Under Network Access, add your current IP address.
  • Click Connect, then Drivers, and copy the connection string into MONGODB_URI in server/.env.

server/config/database.js

import "dotenv/config";
import mongoose from "mongoose";

export async function connectDatabase() {
  await mongoose.connect(process.env.MONGODB_URI, {
    dbName: process.env.MONGODB_DB_NAME,
    serverSelectionTimeoutMS: 10000, // stop waiting after 10 seconds
  });

  console.log("MongoDB connected.");
}

export async function disconnectDatabase() {
  await mongoose.disconnect();
}

server/server.js for MongoDB

Connect to the database before opening the port, so that the first request has a database to use.

import "dotenv/config";
import express from "express";
import { connectDatabase } from "./config/database.js";
import itemsRouter from "./routes/items.js";
import { HttpError } from "./utils/HttpError.js";

const PORT = process.env.PORT || 3000;

const app = express();

app.use(express.json());

app.use("/api/items", itemsRouter);

app.use((req, res) => {
  res.status(404).json({ error: "Route not found." });
});

app.use((error, req, res, next) => {
  if (error instanceof HttpError) {
    return res.status(error.status).json({ error: error.message });
  }

  // Bad data caught by the schema. Do not echo the details back.
  if (["ValidationError", "CastError"].includes(error.name)) {
    return res.status(400).json({ error: "The request contains invalid data." });
  }

  console.error(error);
  res.status(500).json({ error: "An unexpected server error occurred." });
});

try {
  await connectDatabase();

  app.listen(PORT, () => {
    console.log(`🚀 Server listening on http://localhost:${PORT}`);
  });
} catch (error) {
  console.error("Could not connect to MongoDB:", error.message);
  process.exitCode = 1;
}

Starter Schema And CRUD

This is the smallest full setup. It uses the routes file and HttpError.js from the Node page, and it answers the same way as the Postgres version, so the React pages work with either one.

server/models/Item.js

toJSON changes what gets sent to the browser. It adds an id field and removes _id and __v, so React can use item.id.

import mongoose from "mongoose";

const itemSchema = new mongoose.Schema(
  {
    title: {
      type: String,
      required: true,
      trim: true,
      maxlength: 255,
    },
    description: {
      type: String,
      trim: true,
      maxlength: 10000,
      default: "",
    },
    image: {
      type: String,
      trim: true,
      maxlength: 2000,
      default: "",
    },
  },
  {
    timestamps: true, // adds createdAt and updatedAt
    collection: "items",
    toJSON: {
      virtuals: true,
      versionKey: false,
      transform(document, result) {
        delete result._id;
        return result;
      },
    },
  },
);

const Item = mongoose.model("Item", itemSchema);

export default Item;

server/utils/readObjectId.js

A MongoDB id is 24 hexadecimal characters. Anything else gets a 404 before it reaches the database.

import { HttpError } from "./HttpError.js";

export function readObjectId(value) {
  if (typeof value !== "string" || !/^[a-f0-9]{24}$/i.test(value)) {
    throw new HttpError(404, "Item not found.");
  }

  return value.toLowerCase();
}

server/controllers/items.js

This uses Express 5, where a thrown error goes to the error handler in server.js. pickFields only copies the fields you allow, so a user cannot set a field like role by adding it to the request.

import Item from "../models/Item.js";
import { HttpError } from "../utils/HttpError.js";
import { readObjectId } from "../utils/readObjectId.js";

const pickFields = (body) => {
  if (!body || typeof body !== "object" || Array.isArray(body)) {
    throw new HttpError(400, "Send a JSON object.");
  }

  if (typeof body.title !== "string" || !body.title.trim()) {
    throw new HttpError(400, "Title is required.");
  }

  return {
    title: body.title,
    description: String(body.description ?? ""),
    image: String(body.image ?? ""),
  };
};

const findItem = async (id) => {
  const item = await Item.findById(readObjectId(id));

  if (!item) throw new HttpError(404, "Item not found.");
  return item;
};

const getItems = async (req, res) => {
  const items = await Item.find({}).sort({ createdAt: 1 });

  res.status(200).json(items);
};

const getItemById = async (req, res) => {
  res.status(200).json(await findItem(req.params.id));
};

const createItem = async (req, res) => {
  const item = await Item.create(pickFields(req.body));

  res.status(201).json(item);
};

// save() runs the schema rules. findByIdAndUpdate skips them by default.
const updateItem = async (req, res) => {
  const item = await findItem(req.params.id);

  Object.assign(item, pickFields(req.body));
  await item.save();
  res.status(200).json(item);
};

const deleteItem = async (req, res) => {
  const item = await findItem(req.params.id);

  await item.deleteOne();
  res.status(200).json(item);
};

export default {
  getItems,
  getItemById,
  createItem,
  updateItem,
  deleteItem,
};

Indexes

An index makes a search fast. Add one for each way your pages sort or filter a large collection.

// Newest first. _id breaks ties when two have the same time.
postSchema.index({ createdAt: -1, _id: -1 });

// All posts by one author, newest first.
postSchema.index({ authorId: 1, createdAt: -1 });

// One vote for each user on each post.
voteSchema.index({ postId: 1, userId: 1 }, { unique: true });

// MongoDB deletes the document after this date. It can run up to a minute late.
tokenSchema.index({ expiresAt: 1 }, { expireAfterSeconds: 0 });

These are the real Rev models. They show one to many links, a unique pair, and rules that depend on another field. Each one imports the two files right below.

server/config/mongooseSecurity.js

Add import "../config/mongooseSecurity.js"; at the top of every model file. It blocks query injection and cancels runaway queries for every model.

// database-wide safety settings for Mongoose.
//
// Every model file imports this module BEFORE it creates its schema, so these
// rules apply to every model automatically, including ones you add later.
// When you create a new model, add this import at the top of the file:
//
//   import "../config/mongooseSecurity.js";

import mongoose from "mongoose";

// --- 1. Neutralize query-operator injection --------------------------------
// With sanitizeFilter on, if a value inside a query filter is an object that
// contains "$" keys (for example { email: { $ne: null } } built from untrusted
// input), Mongoose wraps it in { $eq: ... }. The query then looks for that
// literal object instead of running the operator, so it matches nothing or
// throws a CastError. It also refuses $where, $expr, $jsonSchema, and $text
// at the top of a filter.
//
// This is a SAFETY NET behind the HTTP input checks, not a replacement for them.
//
// IMPORTANT FOR FUTURE ROUTES: when YOUR server code needs an operator,
// mark that piece of the filter as trusted:
//
//   import { trusted } from "../config/mongooseSecurity.js";
//   Post.find({ rating: trusted({ $gte: minimumRating }) });
//
// Aggregation pipelines (Model.aggregate) are NOT sanitized. Build $match
// stages only from values you have already validated.
mongoose.set("sanitizeFilter", true);

export const trusted = mongoose.trusted;

// --- 2. Stop runaway queries from tying up the database ---------------------
// A slow query (for example a future search box using a regex) can be fired
// repeatedly by a bot to overload the database. maxTimeMS tells MongoDB to
// cancel any read that runs longer than this. A route can still set its own
// limit with .maxTimeMS(ms) when it genuinely needs longer.
export const DEFAULT_QUERY_TIME_LIMIT_MS = 5000;
export const DEFAULT_AGGREGATE_TIME_LIMIT_MS = 15000;

const READ_QUERIES = [
  "find",
  "findOne",
  "countDocuments",
  "estimatedDocumentCount",
  "distinct",
];

function queryTimeLimitPlugin(schema) {
  schema.pre(READ_QUERIES, function applyQueryTimeLimit() {
    if (this.getOptions().maxTimeMS == null) {
      this.maxTimeMS(DEFAULT_QUERY_TIME_LIMIT_MS);
    }
  });

  schema.pre("aggregate", function applyAggregateTimeLimit() {
    if (this.options?.maxTimeMS == null) {
      this.option({ maxTimeMS: DEFAULT_AGGREGATE_TIME_LIMIT_MS });
    }
  });
}

// Register once per process, even if many model files import this module.
if (!mongoose.__revQueryTimeLimitPlugin) {
  mongoose.plugin(queryTimeLimitPlugin);
  Object.defineProperty(mongoose, "__revQueryTimeLimitPlugin", { value: true });
}

server/models/validators.js

Shared rules for usernames, emails, and links. The model and the API both use this file, so they can never disagree.

// Shared format rules used by BOTH the Mongoose models and the HTTP input
// parsers in security/input.js. Keeping one copy means the database and the
// API can never disagree about what a valid username, email, or link is.

// Usernames are shown publicly next to reviews and posts.
// Only plain letters, digits, underscore, hyphen, and period are allowed, and
// the first and last characters must be a letter or digit. This blocks
// look-alike Unicode names (for example a Cyrillic "а" posing as "a"),
// invisible characters, and names that are only punctuation.
export const USERNAME_PATTERN = /^[A-Za-z0-9](?:[A-Za-z0-9_.-]*[A-Za-z0-9])?$/;

// Case-insensitive comparison rule for usernames. "Sam", "sam",
// and "SAM" are treated as the same name by the unique database index.
export const USERNAME_COLLATION = Object.freeze({ locale: "en", strength: 2 });

// Basic email shape check. \s blocks spaces and line breaks
// (which also stops email-header injection), \p{Cc} blocks control
// characters, and \p{Cf} blocks invisible formatting characters such as
// zero-width spaces. A format check still does NOT prove mailbox ownership.
export const EMAIL_PATTERN =
  /^[^\s@\p{Cc}\p{Cf}]+@[^\s@\p{Cc}\p{Cf}]+\.[^\s@\p{Cc}\p{Cf}]+$/u;

// Links and image addresses stored in the database.
// Browsers treat some URL schemes as code (javascript:) or as embedded
// documents (data:, file:), so only real web addresses are accepted.
// allowRelative lets admin-managed records point at the site's own assets,
// such as "/images/cover.png", but never at "//other-site.example".
export function isSafeWebUrl(
  value,
  { allowRelative = false, allowHttp = false } = {},
) {
  // Optional fields may be empty; "required" rules handle mandatory ones.
  if (value === undefined || value === null || value === "") return true;
  if (typeof value !== "string" || value.length > 2000) return false;

  // A site-relative path: starts with exactly one "/" and uses safe characters.
  if (allowRelative && /^\/(?!\/)[A-Za-z0-9._~\-/]+$/.test(value)) return true;

  let url;
  try {
    url = new URL(value);
  } catch {
    return false;
  }

  const allowedProtocols = allowHttp ? ["https:", "http:"] : ["https:"];

  // Reject other schemes, embedded usernames/passwords, and empty hosts.
  return (
    allowedProtocols.includes(url.protocol) &&
    !url.username &&
    !url.password &&
    url.hostname.length > 0
  );
}

// Mongoose validator factory, e.g. validate: safeUrl({ allowRelative: true })
export function safeUrl(options = {}) {
  return {
    validator: (value) => isSafeWebUrl(value, options),
    message: options.allowRelative
      ? "Use an https:// address or a site path that starts with /."
      : "Use a full https:// address.",
  };
}

      // https:// address or a site path such as /images/header.png.
      validate: safeUrl({ allowRelative: true }),
    },

    // One game can reference multiple Category documents.
    categoryIds: {
      // Array of ObjectIds referencing Category documents, with a maximum of 10 unique categories.
      type: [
        {
          type: mongoose.Schema.Types.ObjectId,
          ref: "Category",
        },

      default: [],
      validate: {
        validator: function (ids) {

          return ids.length <= 10 && uniqueIds.size === ids.length;

        message: "Choose up to 10 categories without duplicates.",
      },
    },

    // Initially represents your own recorded playtime.
    playtimeHours: {
      type: Number,
      min: 0,
      default: 0,
    },
  },
  {
    timestamps: true,
    collection: "games",
  },
);

server/models/Post.js

One user has many posts, so each post saves its author's id. A review needs a game and a rating, and a discussion cannot have them.

// Post for each user and a user can have many posts
// one to many relationship between user and post

import mongoose from "mongoose";
// database-wide safety settings; must load before the schema below.
import "../config/mongooseSecurity.js";
// only real https:// links may be stored.
import { safeUrl } from "./validators.js";

const postSchema = new mongoose.Schema(
  {
    // Reference to the User model-not the filename.
    authorId: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "User",
      required: true,
    },

    // Reviews require a game; discussions do not.
    gameId: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Game",
      required: function () {
        return this.kind === "review";
      },
    },

    // The kind of post, either "review" or "discussion".
    kind: {
      type: String,
      enum: ["review", "discussion"],
      default: "discussion",
      required: true,
    },

    // The title of the post, required for both reviews and discussions.
    title: {
      type: String,
      required: true,
      trim: true,
      maxlength: 400,
    },

    // The body of the post, required for both reviews and discussions.
    body: {
      type: String,
      required: true,
      trim: true,
      maxlength: 10000,
    },

    // The image URL of the post, optional.
    imageUrl: {
      type: String,
      trim: true,
      maxlength: 2000,
      // members write posts, so this link is untrusted. Only
      // https:// addresses are accepted: no javascript:, data:, or file: links.
      validate: safeUrl(),
    },
    // Rating is required for reviews and not allowed for discussions.
    rating: {
      type: Number,
      min: 1,
      max: 10,
      required: function () {
        return this.kind === "review";
      },
    },
    // Recommendation is optional for reviews; there is no default value.
    recommend: {
      type: Boolean,
    },
  },
  {
    timestamps: true,
    collection: "posts",
  },
);

// Cross-field rule: disucssions should not contain review-only fields.
// This runs during document validation, including before save().
postSchema.pre("validate", function () {
  if (this.kind === "discussion") {
    if (this.rating !== undefined) {
      this.invalidate("rating", "Ratings belong to review posts only.");
    }

    if (this.recommend !== undefined) {
      this.invalidate(
        "recommend",
        "Recommendations belong to review posts only.",
      );
    }
  } // Both checks belong inside this condition.
});

// Supports displaying the newest posts first.
// _id provides a consistent tie-breaker for identical timestamps.
postSchema.index({ createdAt: -1, _id: -1 });

// indexes planned in the ERD for "a user's
// posts" and "a game's reviews" pages. Without them, those future queries
// scan the whole collection, which a bot can repeat to slow the database.
postSchema.index({ authorId: 1, createdAt: -1 });
postSchema.index({ gameId: 1, createdAt: -1 });

const Post = mongoose.model("Post", postSchema);
export default Post;

Query Reference

Create

Read

await Item.find({});                              // everything

await Item.countDocuments({ kind: "review" });    // how many
await Item.exists({ title: "New item" });         // found or null
await User.findOne({ email }).select("+passwordHash"); // include a hidden field
await Item.find({}).select("title image");        // only these fields

Sort and pages

const limit = 24;

const items = await Item.find({})
  .sort({ createdAt: -1 }) // -1 is newest first, 1 is oldest first
  .skip((page - 1) * limit)
  .limit(limit);

Filter operators

If the Rev mongooseSecurity.js file is loaded, wrap operators you wrote yourself in trusted().

import { trusted } from "../config/mongooseSecurity.js";

await Post.find({ rating: trusted({ $gte: 8 }) });          // 8 or higher
await Post.find({ kind: trusted({ $in: ["review"] }) });    // any of these
await Post.find({ imageUrl: trusted({ $exists: true }) });  // field is there

Fill in linked documents with populate

Like a SQL JOIN. Name the ref field and the fields you want. Always choose the fields so private data stays out.

const posts = await Post.find({}).populate("authorId", "username");

Update

// Best: load it, change it, save it. This runs every schema rule.
const item = await Item.findById(id);
item.title = "Changed";
await item.save();

// One step, for counters. $inc adds to the number.
await User.updateOne({ _id: id }, { $inc: { sessionVersion: 1 } });
await User.updateOne({ _id: id }, { $set: { status: "banned" } }, { runValidators: true });

Delete

await item.deleteOne();
await Item.deleteOne({ _id: id });
await Comment.deleteMany({ postId: id }); // clean up records that point at it

Block a delete when records still point at it

if (await Post.exists({ gameId: id })) {
  throw new HttpError(409, "This game still has reviews. Delete the reviews first.");
}

Change several documents together with a transaction

All of it saves or none of it does. Atlas supports this. A plain local mongod needs to run as a replica set first.

const session = await mongoose.startSession();

try {
  await session.withTransaction(async () => {
    await Comment.deleteMany({ postId: id }, { session });
    await Post.deleteOne({ _id: id }, { session });
  });
} finally {
  await session.endSession();
}

SELECT * ... WHERE id = $1         Item.findById(id)
INSERT INTO ... RETURNING *        Item.create(fields)
UPDATE ... WHERE id = $1           load it, change it, item.save()
DELETE ... WHERE id = $1           item.deleteOne()
