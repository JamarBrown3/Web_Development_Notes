What is HTML

Web pages are created using HyperText Markup Language (HTML), which is the authoring language used to create documents on the World Wide Web. HTML uses a set of special instructions called tags or markup to define the structure and layout of a Web document and specify how the page is displayed in a browser. Most elements have an opening tag and a closing tag, with the content between them. For example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Opening And Closing Tags</title>
</head>
<body>
  <!-- <b> is the opening tag and </b> is the closing tag. The text between them is the content. -->
  <b>This text is bold</b>
</body>
</html>

Not all elements consist of opening and closing tags. Some elements simply receive their content or behavior from attributes within a single tag. For example, <meta> and <br> are self-closing tags. Other self-closing tags are: <embed>, <hr>, <img>, <input>, <link>, <param>, <source>, <wbr>.

Document Structure

DOCTYPE Declaration

The <!DOCTYPE html> is a modern declaration to tell the browser: "This document uses HTML5". It makes browsers render the page in standards mode, which is the modern way, instead of the old quirks mode. 

<!DOCTYPE html>
<!-- The line above is the DOCTYPE. It is always line 1, and it tells the browser this is an HTML5 page. -->
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>DOCTYPE Declaration</title>
</head>
<body>
  <p>This page starts with a DOCTYPE.</p>
</body>
</html>

HTML Root Element

The <html lang="en"> tag serves as the root container for the entire HTML document. It should be the first element (after the DOCTYPE declaration) and wraps all other content on the page. 

<!DOCTYPE html>
<!-- The root element. Everything else on the page goes inside it. lang="en" says the page is in English. -->
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>HTML Root Element</title>
</head>
<body>
  <p>All the content for the page goes in here.</p>
</body>
</html>

Head Section

The <head> section contains invisible page settings and information. It defines the character encoding, viewport for mobile devices, page title, and metadata like author and description. This information helps browsers and search engines understand your page. 

<!DOCTYPE html>
<html lang="en">
<head>
  <!-- The character set. UTF-8 covers every language and symbols such as © and €. -->
  <meta charset="UTF-8">
  <!-- Makes the page fit the width of a phone screen. -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <!-- Who wrote the page. -->
  <meta name="author" content="Your name">
  <!-- The short text a search engine shows under the page title. -->
  <meta name="description" content="Description of the page">
  <!-- The text on the browser tab. -->
  <title>Page Title</title>
</head>
<body>
  <p>Nothing in the head shows on the page itself.</p>
</body>
</html>

Pro-Tip: Check that every tag ends with a >. One missing > in the head can hide the whole page, because the browser reads everything after it as part of that tag.

Body Section

The <body> tag contains all the visible content that users see in their browser window. This includes text, images, links, buttons, and any other elements that make up the webpage interface. Everything inside <body> appears on the actual page. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Body Section</title>
</head>
<!-- Everything a visitor sees goes between <body> and </body>. -->
<body>
  <!-- Visible content goes here -->
  <p>This text is visible on the page.</p>
</body>
</html>

Basic Text Elements

Paragraph

The <p> tag defines a paragraph of text. The browser adds space before and after each paragraph. Extra spaces and line breaks inside a paragraph are shown as one single space. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Paragraph</title>
</head>
<body>
  <!-- One paragraph. The browser adds space above and below it. -->
  <p>This is a paragraph of text.</p>
</body>
</html>

Headings (h1-h6)

The <h1> through <h6> tags define HTML headings, with <h1> being the highest (most important) level and <h6> being the lowest. They create a visual and structural hierarchy for your content, similar to chapters and subchapters in a book. Each heading is shown in a smaller font than the one before it, and the browser adds one line before and one line after every heading. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Headings</title>
</head>
<body>
  <!-- Use one <h1> on a page, for the main title. -->
  <h1>Main Title</h1>
  <!-- Go down one level at a time and do not skip a level. -->
  <h2>Section Title</h2>
  <h3>Subsection Title</h3>
  <h4>Subsection Title</h4>
  <h5>Subsection Title</h5>
  <h6>Subsection Title</h6>
</body>
</html>

Pro-Tip: Pick a heading by its meaning, not by its size. Screen readers and search engines use h1 to h6 as the outline of the page. Change the size with CSS instead.

Bold Text

The <b> tag makes text appear in bold without giving it any extra importance or semantic meaning. It's purely for visual styling. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Bold Text</title>
</head>
<body>
  <!-- Bold for looks only. It adds no extra meaning. -->
  <b>This text is bold</b>
</body>
</html>

Strong Text

The <strong> tag marks text as important. Browsers show it in bold, the same as <b>, but screen readers and search engines also know that it matters.

The <strong> element indicates that its contents have strong importance, seriousness, or urgency. Browsers typically render this text in bold, but its purpose is semantic rather than purely visual. 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Strong Text</title>
</head>
<body>
  <!-- Looks bold too, but also tells screen readers that this text is important. -->
  <strong>This text is important!</strong>
</body>
</html>

Line Break

The <br> HTML element produces a line break in text (carriage-return). It is a void element, meaning it has no content and no closing tag. Use it within paragraphs or other text containers to force text onto a new line. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Line Break</title>
</head>
<body>
  <!-- <br> has no closing tag. The text after it starts on a new line. -->
  <p>First line<br>Second line</p>
</body>
</html>

Italic text or Emphasis

The <i> tag applies italic styling to text for purely visual purposes, while <em> (emphasis) adds semantic meaning indicating stressed emphasis. Both typically appear italicized, but <em> carries importance for screen readers and search engines, unlike <i> which is purely presentational.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Italic And Emphasis</title>
</head>
<body>
  <!-- Italic for looks only. -->
  <i>This text is italicized</i>
  <!-- Looks italic too, but also tells screen readers to stress this text. -->
  <em>Emphasized text</em>
</body>
</html>

Strikethrough

The <s> HTML element renders text with a strikethrough line to indicate content that is no longer accurate or relevant.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Strikethrough</title>
</head>
<body>
  <!-- Draws a line through the text. -->
  <s>This text is no longer accurate</s>
</body>
</html>

Underlined Text

The <u> tag applies underlined styling to text for purely visual emphasis. Unlike semantic elements, it doesn't convey specific meaning—it's simply presentational styling to make text stand out visually.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Underlined Text</title>
</head>
<body>
  <!-- Underlines the text. Visitors can mistake underlined text for a link. -->
  <u>This is a paragraph</u>
</body>
</html>

Horizontal Rule

The <hr> HTML element represents a thematic break between paragraph-level elements, creating a horizontal line to visually separate content sections. It is a void element with no closing tag. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Horizontal Rule</title>
</head>
<body>
  <p>Section one content</p>
  <!-- Draws a line across the page. <hr> has no closing tag. -->
  <hr>
  <p>Section two content</p>
</body>
</html>

Link with Href Attribute

Attributes generally go inside the opening HTML tag, like <a href="value">. The attribute name is a predefined name from the HTML specification. There are many: href, title, class, src, etc. The attribute value is the data for the attribute, enclosed in quotes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Link With Href Attribute</title>
</head>
<body>
  <!-- href is the attribute name and the address in quotes is the attribute value. -->
  <a href="https://www.bmcc.cuny.edu">BMCC</a>
</body>
</html>

Block Elements vs Inline elements

One major concept to grasp in HTML is the difference between block elements and inline elements. When you're first getting into positioning and layout with HTML and CSS, it can be confusing as to why some things are placed on the screen the way they are.

  • Block elements take up the full width available on a web page, effectively blocking out any other elements from sitting next to them on the left or right.
  • Inline elements only take up as much width as is needed to display their contents, so other elements can sit in line with them.
  • Common block elements: Paragraphs (<p>), Headers (<h1> through <h6>), Divisions (<div>), Lists and List Items (<ol>, <ul>, <li>), Forms (<form>).
  • Common inline elements: Spans (<span>), Images (<img>), Anchors (<a>).

Block Element

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Block Elements</title>
</head>
<body>
    <!-- Each <div> is a block element, so the three land on three separate lines. -->
    <div>First</div><div>Second</div><div>Third</div>
</body>
</html>

Inline Element

<!DOCTYPE html>
<html lang="en">
<head>
 <meta charset="UTF-8">
 <title>Inline Element</title>
</head>
<body>
 <!-- <img> is an inline element, so the three images sit side by side on one line. -->
 <img src="https://placehold.co/300x450" alt="Placeholder 1">
 <img src="https://placehold.co/300x500" alt="Placeholder 2">
 <img src="https://placehold.co/350x600" alt="Placeholder 3">
</body>
</html>

Pro-Tip: This box used to load its pictures from placekitten.com, which kept going down, so it now uses placehold.co. Any outside image site can stop working. In a real project, keep the images in your own project folder.

Container Elements

Division (div)

The <div> HTML element is a generic container for flow content that has no inherent semantic meaning. It's commonly used with the class attribute for CSS styling and JavaScript manipulation, allowing you to group and style blocks of content together.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Division</title>
</head>
<body>
  <!-- A box with no meaning of its own. The class name is what CSS and JavaScript use to find it. -->
  <div class="container">
    <p>Content inside a div</p>
  </div>
</body>
</html>

Span

The <span> tag is an inline container used to mark up part of a text or document for styling or scripting. Unlike <div> which creates block-level containers, <span> stays within the flow of text, making it ideal for applying CSS classes to specific words or phrases without breaking the content layout.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Span</title>
</head>
<body>
  <!-- <span> wraps only the one word, and the sentence stays on one line. -->
  <p>This is <span class="highlight">highlighted</span> text.</p>
</body>
</html>

Code Element

The <code> HTML element displays its contents styled in a fashion intended to indicate that the text is a short fragment of computer code. By default, browsers render <code> text in a monospace (fixed-width) font like Courier, making it distinct from surrounding content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Code Element</title>
</head>
<body>
  <!-- The text inside <code> is shown in a fixed-width font. -->
  <p>Use <code>console.log()</code> for debugging.</p>
</body>
</html>

Preformatted Text

The <pre> HTML element represents preformatted text which is to be presented exactly as written in the HTML file. Text within a <pre> element is displayed in a fixed-width font, and both spaces and line breaks are preserved, unlike regular HTML where whitespace is collapsed.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Preformatted Text</title>
</head>
<body>
  <!-- Spaces and line breaks inside <pre> are kept exactly as typed. -->
  <pre>
    This text
    keeps    its
    formatting.
  </pre>
</body>
</html>

List Elements

List Item

The <li> (list item) element defines an individual item inside parent list containers: <ul> for unordered (bulleted) lists or <ol> for ordered (numbered) lists. Multiple <li> elements create the actual list content, with browsers automatically adding bullets or numbers.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>List Item</title>
</head>
<body>
  <ul>
    <!-- An <li> always goes inside a <ul> or an <ol>. -->
    <li>List item content</li>
  </ul>
</body>
</html>

Unordered List

The <ul> HTML element represents an unordered list of items, typically rendered as a bulleted list. It serves as a container for <li> (list item) elements, grouping related items where the order doesn't matter semantically.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Unordered List</title>
</head>
<body>
  <!-- A bulleted list. The order of the items does not matter. -->
  <ul>
    <li>First item</li>
    <li>Second item</li>
  </ul>
</body>
</html>

Ordered List

The <ol> HTML element represents an ordered list of items, typically rendered as a numbered list. It contains <li> (list item) elements where the sequence matters, such as instructions, rankings, or step-by-step procedures.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Ordered List</title>
</head>
<body>
  <!-- A numbered list. The browser adds the numbers for you. -->
  <ol>
    <li>First step</li>
    <li>Second step</li>
  </ol>
</body>
</html>

Description List

The <dl> HTML element represents a description list, containing groups of terms (<dt>) and descriptions (<dd>). It's commonly used for glossaries, metadata displays, or any name-value pair listings where terms need associated explanations.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Description List</title>
</head>
<body>
  <dl>
    <!-- <dt> is the term. -->
    <dt>HTML</dt>
    <!-- <dd> is the description of that term. -->
    <dd>HyperText Markup Language</dd>
  </dl>
</body>
</html>

Links & Navigation

Anchor (Link)

The <a> HTML element (anchor) creates hyperlinks to other web pages, files, locations within the same page, email addresses, or any URL. The essential href attribute specifies the link destination, while the link text appears between the opening and closing tags.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Anchor Link</title>
</head>
<body>
  <!-- page.html has to be a file in the same folder as this page. -->
  <a href="page.html">Click here</a>
</body>
</html>

External Link with Target

The target="_blank" attribute in an <a> tag opens the linked document in a new browser tab or window. This keeps your original page open while allowing users to explore external content, improving navigation for external references, documentation, or resources.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>External Link With Target</title>
</head>
<body>
  <!-- target="_blank" opens the link in a new tab. rel="noopener noreferrer" keeps the new tab away from this page. -->
  <a href="https://example.com" target="_blank" rel="noopener noreferrer">Visit Example</a>
</body>
</html>

Pro-Tip: Add rel="noopener noreferrer" whenever target="_blank" points at a site you do not control. It stops the new tab from reaching back into your page.

Email Link

The mailto: protocol in an <a> tag's href attribute creates a link that opens the user's default email client with a new message. When clicked, it pre-fills the recipient address, and can optionally include subject, body, and CC/BCC fields using URL parameters.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Email Link</title>
</head>
<body>
  <!-- mailto: opens the visitor's email app with this address filled in. -->
  <a href="mailto:email@example.com">Send Email</a>
</body>
</html>

Internal Bookmarks

Internal bookmarks use fragment identifiers (#) in <a> tags to link to specific sections within the same page. The href="#id" points to an element with a matching id attribute, allowing users to jump directly to that location without scrolling manually.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Internal Bookmarks</title>
</head>
<body>
  <!-- The # means: jump to the element on this page with that id. -->
  <a href="#section1">Go to Section 1</a>

  <!-- The rest of the page goes here. -->

  <!-- The id has to match the text after the # exactly. -->
  <h2 id="section1">Section 1</h2>
</body>
</html>

Images & Media

Image Element

The <img> HTML element embeds an image into the document. It requires two essential attributes: src (source) specifies the image file path or URL, while alt (alternative text) provides descriptive text for accessibility, screen readers, and when images cannot load.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Image Element</title>
</head>
<body>
  <!-- src is where the image file is. alt is read out by screen readers and shown when the image does not load. -->
  <img src="image.jpg" alt="Description of image">
</body>
</html>

Pro-Tip: Never leave alt out. For a picture that is only decoration, write alt="" so that screen readers skip it.

Image as Link

Wrapping an <img> element inside an <a> tag creates a clickable image link. The image acts as the link's visual content, with the href attribute determining the destination. Always include descriptive alt text for accessibility since the image serves as interactive content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Image As Link</title>
</head>
<body>
  <!-- The image is the clickable part, so the alt text should say where the link goes. -->
  <a href="page.html"><img src="button.jpg" alt="Click me"></a>
</body>
</html>

HTML Entities (Special Characters)

Non-breaking Space

The &nbsp; HTML entity (non-breaking space) creates a space character that prevents browsers from breaking a line at that position. It ensures that connected words or values (like "$10 USD") stay together on the same line, maintaining readability and preventing awkward line breaks.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Non-breaking Space</title>
</head>
<body>
  <!-- &nbsp; is a space that never breaks, so $10 and USD always stay on the same line. -->
  <p>Price: $10&nbsp;USD</p>
</body>
</html>

Less Than & Greater Than

The &lt; and &gt; HTML entities allow you to display the literal characters < and > without browsers interpreting them as HTML tags. Use &lt; for "less than" (<) and &gt; for "greater than" (>) when displaying code examples or mathematical expressions.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Less Than And Greater Than</title>
</head>
<body>
  <!-- &lt; shows < and &gt; shows >. Typed as plain < and >, the browser would read them as a tag. -->
  <p>5 &lt; 10 and 10 &gt; 5</p>
</body>
</html>

Pro-Tip: A plain < in your text can break the page, because the browser thinks a tag is starting. Write &lt; and &amp; in the HTML file when you want the symbols themselves to show.

Ampersand

The &amp; HTML entity displays the ampersand symbol (&) without browsers interpreting it as the start of another character entity. Since & begins all HTML entities, you must use &amp; when you want to show a literal ampersand character in your content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Ampersand</title>
</head>
<body>
  <!-- &amp; shows a plain & on the page. -->
  <p>Company &amp; Co.</p>
</body>
</html>

Copyright & Trademark

The &copy; and &reg; HTML entities display copyright (©) and registered trademark (®) symbols. Use &copy; for copyright notices like "© 2024 Company" and &reg; for registered trademarks, ensuring proper legal symbols appear consistently across all browsers and devices.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Copyright And Trademark</title>
</head>
<body>
  <!-- &copy; shows © and &reg; shows ®. -->
  <p>&copy; 2024 &amp; &reg; BrandName</p>
</body>
</html>

Currency Symbols

HTML entities like &dollar;, &euro;, and &pound; display currency symbols consistently across different systems. Use &dollar; for dollar ($), &euro; for euro (€), and &pound; for pound sterling (£) to ensure currency symbols render properly regardless of the user's language or font settings. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Currency Symbols</title>
</head>
<body>
  <!-- &dollar; shows $, &euro; shows € and &pound; shows £. -->
  <p>Price: &dollar;100 &amp; &euro;90 &amp; &pound;80</p>
</body>
</html>

External Resources

Linking CSS

The <link> element with rel="stylesheet" connects an external CSS file to an HTML document, typically placed inside the <head> section. The href attribute specifies the path to the CSS file, allowing you to separate styling from HTML structure for cleaner, more maintainable code.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Linking CSS</title>
  <!-- Goes in the head. styles.css has to be a file in the same folder as this page. -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <p>This page is styled by styles.css.</p>
</body>
</html>

Linking Bootstrap

The <link> element connects the Bootstrap CSS framework to your HTML document, providing pre-designed responsive components and layout systems. By linking bootstrap.min.css (the minified version), you enable Bootstrap's grid system, components, and utilities while ensuring faster loading times.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Linking Bootstrap</title>
  <!-- Bootstrap goes first. bootstrap.min.css has to be a file in the same folder as this page. -->
  <link rel="stylesheet" href="bootstrap.min.css">
  <!-- Your own CSS goes after Bootstrap, so that your rules win. -->
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- btn and btn-primary are Bootstrap classes. -->
  <button class="btn btn-primary">A Bootstrap button</button>
</body>
</html>

Script

The <script> HTML element is used to embed or reference executable JavaScript code. When including the src attribute like <script src="yourscriptfile.js"></script>, it links to an external JavaScript file, typically placed before the closing </body> tag for better page loading performance.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Script</title>
</head>
<body>
  <p id="message">The script can change this text.</p>

  <!-- Goes last in the body, so the elements above already exist when the script runs. -->
  <script src="yourscriptfile.js"></script>
</body>
</html>

HTML 5 Structure Elements

Semantic HTML elements provide meaningful structure to web documents, helping both browsers and developers understand content organization.

  • <section> is a generic container for thematic groupings of content, often used with heading tags (<h1>-<h6>) to define document hierarchy.
  • <article> holds self-contained content that could stand on its own, like a blog post or a news story.
  • <aside> holds supplementary material that is loosely related to the main content, such as a sidebar or a pull quote.
  • <header> goes at the beginning of a section for introductory content and navigation.
  • <nav> marks a collection of navigation links.
  • <figure> pairs media like an image or a video with a caption in <figcaption>.
  • <dialog> marks up a dialog box or a pop-up window.
  • <footer> ends a section with metadata like author information, copyright notices, or related links.

Together, these semantic tags create a clearly defined, accessible document structure that improves SEO, screen reader compatibility, and code maintainability compared to generic <div> containers. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>HTML 5 Structure Elements</title>
</head>
<body>
  <!-- A section groups content that belongs together. -->
  <section class="main-content">
    <!-- The header holds the title and the navigation. -->
    <header>
      <h1>My Awesome Blog</h1>
      <!-- nav wraps the main links. -->
      <nav>
        <a href="#home">Home</a>
        <a href="#about">About</a>
        <a href="#contact">Contact</a>
      </nav>
    </header>

    <!-- An article is content that still makes sense on its own, such as one blog post. -->
    <article>
      <h2>Understanding Semantic HTML</h2>
      <p>Semantic elements clearly describe their meaning...</p>
      
      <!-- A figure ties an image to its caption. -->
      <figure>
        <img src="semantic-html.png" alt="Semantic HTML structure">
        <figcaption>Figure 1: HTML5 Semantic Layout</figcaption>
      </figure>
      
      <!-- An aside is extra content next to the main content. -->
      <aside>
        <h3>Did You Know?</h3>
        <p>HTML5 was published in 2014!</p>

Forms

HTML Forms enable user interaction by collecting data through elements like text fields, buttons, checkboxes, and dropdowns. This data can be sent to servers or processed on the page itself. Each form element should be paired with descriptive labels for accessibility and clear user guidance. From a user experience (UX) point of view, it's important to remember that the bigger your form, the more you risk losing users. Keep it simple and stay focused: ask only for that data you absolutely need.

Form Element

The <form> element defines a container for interactive controls that collect user data. All form elements must be placed inside a <form> tag, but forms cannot be nested within each other. While HTML5 allows form elements outside forms using the form attribute, browser support for this feature is currently inconsistent.

Form elements are different types of input elements, like text fields, checkboxes, radio buttons, select drop-downs, submit buttons and more.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Form Element</title>
</head>
<body>
  <!-- action is where the data is sent. method is how it is sent. -->
  <form action="my-handling-form-page" method="post">
    <!-- form elements -->
  </form>
</body>
</html>

Form element Attributes

Form attributes control submission behavior: action specifies where data is sent, target determines where the response opens (new tab/window), and method defines the HTTP method (GET for visible parameters or POST for secure submission).

  • GET: Data appears in the URL, limited length, good for bookmarks, never for sensitive data.
  • POST: Data is kept out of the URL, no length limits, cannot bookmark, use for sensitive information.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Form Attributes</title>
</head>
<body>
  <!-- GET: the search text shows in the address bar, as ?search=... -->
  <form action="action_page.php" target="_blank" method="get">
    <input type="text" name="search">
    <button type="submit">Search</button>
  </form>
  <!-- POST: the search text is sent in the body of the request, not in the address. -->
  <form action="action_page.php" target="_blank" method="post">
    <input type="text" name="search">
    <button type="submit">Search</button>
  </form>
</body>
</html>

Pro-Tip: POST keeps the data out of the address bar, but it is not encrypted. A password is only safe when the page is on https.

Name attribute of input elements

Input fields require a name attribute for their data to be submitted. Without it, the field's data is ignored and not sent to the server.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Name Attribute</title>
</head>
<body>
  <form action="/action_page.php">
  First name:<br>
    <!-- There is no name on this one, so its value is not sent. -->
    <input type="text" value="Mickey"><br>
  Last name:<br>
    <!-- This one is sent, as lastname=Mouse. -->
    <input type="text" name="lastname" value="Mouse">
  <br>
    <input type="submit" value="Submit">
  </form>
</body>
</html>

</html>

Select 'size' (increasing visible values)

Use the size attribute to specify the number of visible values:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Select Size</title>
</head>
<body>
  <!-- size="2" shows two options at once instead of a drop-down. -->
  <select name="cars" size="2">
      <option value="volvo">Volvo</option>
      <option value="saab">Saab</option>
      <option value="fiat">Fiat</option>
      <option value="audi">Audi</option>
  </select>
</body>
</html>

Textarea

The <textarea> element defines a multi-line input field (a text area). The rows attribute specifies the visible number of lines in a text area. The cols attribute specifies the visible width of a text area. 

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Textarea</title>
</head>
<body>
  <!-- rows is how many lines tall and cols is how many characters wide. -->
  <textarea name="message" rows="10" cols="30">
  The cat was playing in the garden.
  </textarea>
</body>
</html>

Button Element

The <button> element defines a clickable button:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Button Element</title>
</head>
<body>
  <!-- type="button" stops the button from sending a form. onclick runs the JavaScript in the quotes. -->
  <button type="button" onclick="alert('Hello World!')">
  Click Me!
  </button>
</body>
</html>

New HTML 5 Elements

HTML5 added datalist/output elements. Older browsers safely ignore unsupported tags.

Datalist Element

The datalist provides predefined suggestions for input fields through a dropdown, linked via matching id and list attributes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Datalist Element</title>
</head>
<body>
  <form action="result.php">
    <!-- list="browsers" matches the id on the datalist below. -->
    <input list="browsers">
    <!-- The suggestions that show while the visitor types. -->
    <datalist id="browsers">
      <option value="Internet Explorer">
      <option value="Firefox">
      <option value="Chrome">
      <option value="Opera">
      <option value="Safari">
    </datalist>
  </form>
</body>
</html>

Output Element

The <output> element represents the result of a calculation (like one performed by a script). Perform a calculation and show the result in an element:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Output Element</title>
</head>
<body>
  <!-- oninput runs every time a value changes. It adds a and b and puts the answer in x. -->
  <form action="/action_page.php" oninput="x.value=parseInt(a.value)+parseInt(b.value)">
  0
  <input type="range" id="a" name="a" value="50">
  100 +
  <input type="number" id="b" name="b" value="50">
  =
  <!-- The answer shows here. for="a b" lists the ids it is worked out from. -->
  <output name="x" for="a b"></output>
  <br><br>
  <input type="submit">
  </form>
</body>
</html>
