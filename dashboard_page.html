What Is On This Page

Copy and paste pieces for any client dashboard: a print button that makes clean PDFs, and a stats kit that shows how data is spread out (mean, median, standard deviation, IQR, range, outliers) as a histogram with a normal curve, a box plot and a summary table.

Every file here was built and tested together on 4 Nov 2026 with React 19, Recharts 3.10.1 and Vite 7: the charts were rendered, hovered, printed to PDF two ways, and checked at phone width. The stats were checked against NumPy and SciPy and matched to 9 decimal places.

The whole tested project is also in starters/dashboard-kit, so you can copy the folder instead of pasting files one at a time.

src/dashboard-kit/PrintButton.jsx

// PrintButton.jsx: a "Print or save as PDF" button for any dashboard.
// Needs print.css imported once (in main.jsx) so the printout looks right.
//
// Use it:  <PrintButton fileName="Corner Coffee - October report" />
// fileName becomes the suggested name when the client picks "Save as PDF".

export default function PrintButton({ fileName, label = "Print or save as PDF" }) {
  function handlePrint() {
    // The browser names the PDF after the page title, so swap it in for a moment.
    const oldTitle = document.title;
    if (fileName) document.title = fileName;

    // Put the old title back once the print window closes.
    window.addEventListener("afterprint", () => (document.title = oldTitle), { once: true });

    window.print();
  }

  return (
    <button type="button" className="print-button no-print" onClick={handlePrint}>
      {label}
    </button>
  );
}

Sample vs population SD

stats.js divides by n - 1 by default (the sample SD). That's what R sd(), Excel STDEV.S, pandas and Google Sheets STDEV use. Use { sample: false } to divide by n (Excel STDEV.P, NumPy's default std) only when you have every value there will ever be. Dashboards almost always want the sample version.

// Runs on its own next to the dashboard-kit folder: node sd-check.js
import { standardDeviation } from "./dashboard-kit/stats.js";

const values = [2, 4, 4, 4, 5, 5, 7, 9];

// sample: divides by n - 1 (R sd, Excel STDEV.S). Prints 2.138...
console.log(standardDeviation(values));

// population: divides by n (Excel STDEV.P). Prints 2
console.log(standardDeviation(values, { sample: false }));

Quick checks that use your stats skills

  • Mean much bigger than median = right skew (common for money: orders, income, time on page). Report the median as the typical value.
  • In a normal distribution about 68% of values are within 1 SD of the mean, 95% within 2 SD, and 99.7% within 3 SD.
  • Also in a normal distribution the IQR is about 1.35 x SD. If IQR / SD is far from 1.35, the data is probably not normal.
  • The bell curve on the chart is a comparison, not proof. For a real test, run shapiro.test(x) or qqnorm(x); qqline(x) in R.

Why Q1 And Q3 Can Differ Between Tools

There is more than one accepted way to calculate a quartile when it falls between two values. Hyndman and Fan (1996) list nine. With big datasets the answers are almost the same. With small ones they can differ, so say which method you used if a client compares with Excel.

stats.js uses type 7: the default in R, NumPy and pandas, and the same as Excel QUARTILE.INC and PERCENTILE.INC.

ToolFunctionMethod
Rquantile(x) (default)type 7
NumPy / pandasnp.quantile, Series.quantile (default)type 7 (linear)
Excel / Google SheetsQUARTILE.INC, PERCENTILE.INC, QUARTILEtype 7
ExcelQUARTILE.EXC, PERCENTILE.EXCtype 6
SPSS, Minitabdefaulttype 6
stats.jsquantile(values, p)type 7

Example: for 2, 4, 4, 4, 5, 5, 7, 9, type 7 gives Q1 = 4 and Q3 = 5.5 (R, NumPy and stats.js agree).

stats.js

Plain JavaScript with no libraries, so it also works in Node or a server route. Every function takes an array of numbers. Run cleanNumbers first (describe does it for you) so blanks, null and NA don't turn everything into NaN.

The histogram picks its number of bins with the Freedman-Diaconis rule: bin width = 2 x IQR / cube root of n. It uses the IQR, so a few extreme values don't squash all the bars together. It's the same rule as NumPy's bins='fd' and gave the same bin counts in testing.

src/dashboard-kit/stats.js

// stats.js: descriptive statistics for dashboards. Plain JavaScript, no React,
// no libraries, so it works in React, Node, or a plain <script>.
// Every function takes an array of numbers. Missing values (null, "", "NA", NaN)
// are removed first by cleanNumbers.
//
// Matches R's defaults: sd() and var() divide by n - 1, quantile() uses type 7.

// ---------- Cleaning ----------

// [3, "4", null, "NA", NaN, 5]  ->  [3, 4, 5]
export function cleanNumbers(values) {
  return values
    .filter((value) => value !== null && value !== "" && value !== "NA")
    .map(Number)
    .filter(Number.isFinite);
}

// Sorted copy, smallest first (never changes the original array).
function sorted(values) {
  return [...values].sort((a, b) => a - b);
}

// ---------- Center ----------

export function mean(values) {
  return values.reduce((sum, value) => sum + value, 0) / values.length;
}

export function median(values) {
  return quantile(values, 0.5);
}

// ---------- Spread ----------

// sample: true divides by n - 1 (what R, Excel STDEV.S and pandas use).
// sample: false divides by n (Excel STDEV.P), for when you have every value there is.
export function variance(values, { sample = true } = {}) {
  const m = mean(values);
  const squares = values.reduce((sum, value) => sum + (value - m) ** 2, 0);
  return squares / (values.length - (sample ? 1 : 0));
}

export function standardDeviation(values, options) {
  return Math.sqrt(variance(values, options));
}

// p between 0 and 1. quantile(x, 0.25) is Q1, quantile(x, 0.75) is Q3.
// Type 7 (Hyndman and Fan): the default in R, NumPy, pandas and Excel QUARTILE.INC.
export function quantile(values, p) {
  const s = sorted(values);
  const position = (s.length - 1) * p;   // where p falls between the sorted values
  const below = Math.floor(position);
  const above = Math.ceil(position);
  const weight = position - below;       // how far past "below" it sits
  return s[below] + (s[above] - s[below]) * weight;
}

// The middle 50% of the data: Q3 - Q1. Not pulled around by extreme values.
export function iqr(values) {
  return quantile(values, 0.75) - quantile(values, 0.25);
}

// The full spread: biggest minus smallest. One extreme value changes it a lot.
export function range(values) {
  return Math.max(...values) - Math.min(...values);
}

// ---------- Shape ----------

// Sample skewness (the adjusted Fisher-Pearson version, same as Excel SKEW).
// About 0 = symmetric. Positive = long tail to the right. Negative = long tail to the left.
export function skewness(values) {
  const n = values.length;
  const m = mean(values);
  const sd = standardDeviation(values);
  const cubes = values.reduce((sum, value) => sum + ((value - m) / sd) ** 3, 0);
  return (n / ((n - 1) * (n - 2))) * cubes;
}

// How many standard deviations a value is from the mean.
export function zScore(value, m, sd) {
  return (value - m) / sd;
}

// ---------- Outliers (Tukey's fences, the rule box plots use) ----------

export function outlierFences(values, k = 1.5) {
  const q1 = quantile(values, 0.25);
  const q3 = quantile(values, 0.75);
  const spread = q3 - q1;
  return { low: q1 - k * spread, high: q3 + k * spread };
}

export function outliers(values, k = 1.5) {
  const { low, high } = outlierFences(values, k);
  return values.filter((value) => value < low || value > high);
}

// ---------- Everything at once ----------

export function describe(rawValues) {
  const values = cleanNumbers(rawValues);
  const fences = outlierFences(values);
  return {
    count: values.length,
    missing: rawValues.length - values.length,
    mean: mean(values),
    median: median(values),
    sd: standardDeviation(values),
    min: Math.min(...values),
    q1: quantile(values, 0.25),
    q3: quantile(values, 0.75),
    max: Math.max(...values),
    iqr: iqr(values),
    range: range(values),
    skewness: skewness(values),
    fences,
    outliers: values.filter((value) => value < fences.low || value > fences.high),
  };
}

// ---------- Histogram and normal curve ----------

// Bin width from the Freedman-Diaconis rule: 2 * IQR / cube root of n.
// It uses the IQR, so a few extreme values don't wreck the bins.
// Falls back to Sturges' rule if the IQR is 0 (lots of identical values).
export function binCount(values) {
  const n = values.length;
  const width = (2 * iqr(values)) / Math.cbrt(n);
  const spread = range(values);
  if (width <= 0 || spread === 0) return Math.max(1, Math.ceil(Math.log2(n) + 1));
  return Math.min(60, Math.max(5, Math.ceil(spread / width)));
}

// Splits the values into equal-width bins.
// Returns [{ start, end, mid, count }, ...]
export function histogram(values, bins = binCount(values)) {
  const min = Math.min(...values);
  const max = Math.max(...values);
  const width = (max - min) / bins || 1;
  const result = Array.from({ length: bins }, (_, i) => ({
    start: min + i * width,
    end: min + (i + 1) * width,
    mid: min + (i + 0.5) * width,
    count: 0,
  }));
  values.forEach((value) => {
    // The max value belongs in the last bin, not one past it.
    const index = Math.min(bins - 1, Math.floor((value - min) / width));
    result[index].count += 1;
  });
  return result;
}

// Height of the normal (bell) curve at x.
export function normalPdf(x, m, sd) {
  return Math.exp(-0.5 * ((x - m) / sd) ** 2) / (sd * Math.sqrt(2 * Math.PI));
}

Using it

import { describe, quantile, cleanNumbers } from "./dashboard-kit/stats.js";

// "NA" and null are missing values. describe takes them out for you.
const orderTotals = [12.5, 8, "NA", 9.25, 48, null, 11];

const s = describe(orderTotals);
// s.count 5, s.missing 2, s.mean, s.median, s.sd, s.q1, s.q3, s.iqr, s.range, s.outliers ...
console.log(s.count, s.missing, s.median); // 5 2 11

// quantile does not clean the values itself, so run cleanNumbers first.
const p90 = quantile(cleanNumbers(orderTotals), 0.9); // 90th percentile
console.log(p90); // about 33.8

Pro-Tip: With no values at all, describe gives back null for the mean, the median, and the quartiles. With only one value, sd is null. Check s.count before you show the numbers, or the page prints the word null.

Reading A Distribution

  • Blue bars: how many values fall in each range (a histogram).
  • Orange curve: a normal distribution with the same mean and SD, scaled to counts (density x n x bin width) so it shares the bars' y-axis.
  • Solid line = mean, dashed line = median. If they are far apart, the data is skewed.
  • Dark band = IQR (Q1 to Q3, the middle 50%). Light band = mean plus or minus 1 SD.
  • Bars far from the curve mean the data isn't normal. That's normal for money! Talk in medians and IQRs then.

Histogram With A Normal Curve

Recharts has no histogram chart, so this one combines two x-axes in a ComposedChart. The bars sit on a hidden category axis (one slot per bin). The curve, the lines and the shaded bands sit on a number axis with the same start and end. With no padding the two line up exactly (tested: within 0.13 pixels).

Hover a bar to see its range, its count and its share of all values. Every mark is named in the key under the chart, so nothing depends on color alone.

src/dashboard-kit/DistributionChart.jsx

// DistributionChart.jsx: histogram + normal (bell) curve, with the mean, the median,
// +/- 1 standard deviation and the IQR (middle 50%) marked. Built with Recharts 3.3+.
//
// Use it:  <DistributionChart values={orderTotals} unit="$" label="Order total" />
//
// How it lines up: the bars use a hidden category axis (one slot per bin) and the
// curve and markers use a number axis with the same start and end. With no padding,
// slot i covers exactly the same stretch of the chart as bin i, so they match.
import {
  Bar,
  CartesianGrid,
  ComposedChart,
  Line,
  ReferenceArea,
  ReferenceLine,
  Tooltip,
  XAxis,
  YAxis,
} from "recharts";
import { cleanNumbers, describe, histogram, normalPdf } from "./stats.js";

const COLORS = {
  bars: "#3987e5",    // blue
  curve: "#eb6834",   // orange
  mean: "#111827",    // near black, solid line
  median: "#6b7280",  // gray, dashed line
  band: "#9ca3af",    // gray shading
};

export default function DistributionChart({ values, label = "Value", unit = "", decimals = 0, height = 320 }) {
  const data = cleanNumbers(values);
  if (data.length < 3) return <p>Not enough data to show a distribution (need at least 3 values).</p>;

  const s = describe(data);
  const bins = histogram(data);
  const binWidth = bins[0].end - bins[0].start;
  const start = bins[0].start;
  const end = bins[bins.length - 1].end;

  // Bell curve sampled at 100 points across the same range as the bars.
  // normalPdf * count * binWidth = "how many values we'd expect in a bin here".
  const curve = Array.from({ length: 100 }, (_, i) => {
    const x = start + ((end - start) * i) / 99;
    return { x, expected: normalPdf(x, s.mean, s.sd) * data.length * binWidth };
  });

  // Round tick values for the bottom axis, like 0, 10, 20, 30.
  const ticks = niceTicks(start, end);

  const format = (n) => `${unit}${n.toLocaleString("en-US", { maximumFractionDigits: decimals })}`;
  const bars = bins.map((bin, i) => ({ ...bin, slot: i, label: `${format(bin.start)} to ${format(bin.end)}` }));

  return (
    <figure className="distribution print-keep" style={{ margin: 0 }}>
      <ComposedChart
        style={{ width: "100%", height }}
        responsive
        data={bars}
        margin={{ top: 12, right: 24, bottom: 28, left: 8 }}
        barCategoryGap={1}
      >
        <CartesianGrid vertical={false} stroke="#e5e7eb" />

        {/* Hidden slot axis for the bars. */}
        <XAxis xAxisId="bins" dataKey="slot" type="category" hide padding={{ left: 0, right: 0 }} />

        {/* Visible number axis for the curve, the markers and the tick labels. */}
        <XAxis
          xAxisId="num"
          type="number"
          dataKey="x"
          domain={[start, end]}
          allowDataOverflow
          tickFormatter={format}
          ticks={ticks}
          height={30}
          stroke="#9ca3af"
        />
        <YAxis allowDecimals={false} stroke="#9ca3af" width={44} label={{ value: "Count", angle: -90, position: "insideLeft" }} />

        {/* Shaded bands: middle 50% (IQR), then mean +/- 1 SD as a lighter band. */}
        <ReferenceArea xAxisId="num" x1={Math.max(start, s.mean - s.sd)} x2={Math.min(end, s.mean + s.sd)} fill={COLORS.band} fillOpacity={0.12} />
        <ReferenceArea xAxisId="num" x1={s.q1} x2={s.q3} fill={COLORS.band} fillOpacity={0.22} />

        <Bar xAxisId="bins" dataKey="count" name="Count" fill={COLORS.bars} radius={[3, 3, 0, 0]} isAnimationActive={false} />

        <Line
          xAxisId="num"
          data={curve}
          dataKey="expected"
          name="Normal curve"
          type="monotone"
          stroke={COLORS.curve}
          strokeWidth={2}
          dot={false}
          activeDot={false}
          isAnimationActive={false}
        />

                {/* Mean = solid line, median = dashed line. Their values are in the key below,
            because labels on the lines collide when the two are close together. */}
        <ReferenceLine xAxisId="num" x={s.mean} stroke={COLORS.mean} strokeWidth={2} />
        <ReferenceLine xAxisId="num" x={s.median} stroke={COLORS.median} strokeWidth={2} strokeDasharray="5 4" />

        <Tooltip content={<BinTooltip total={data.length} />} cursor={{ fill: "rgba(0,0,0,0.05)" }} />
      </ComposedChart>

      {/* Key: every mark explained in words, so nothing depends on color alone. */}
      <figcaption style={{ display: "flex", flexWrap: "wrap", gap: "6px 18px", fontSize: 13, color: "#374151" }}>
        <span><Swatch color={COLORS.bars} /> {label} counts</span>
        <span><Swatch color={COLORS.curve} line /> Normal curve (same mean and SD)</span>
        <span><Swatch color={COLORS.mean} line /> Mean {format(s.mean)}</span>
        <span><Swatch color={COLORS.median} line dashed /> Median {format(s.median)}</span>
        <span><Swatch color={COLORS.band} faded={0.45} /> Middle 50% (IQR) {format(s.q1)} to {format(s.q3)}</span>
        <span><Swatch color={COLORS.band} faded={0.2} /> Within 1 SD ({format(s.sd)}) of the mean</span>
      </figcaption>
    </figure>
  );
}

// Small color key used in the caption.
function Swatch({ color, line = false, dashed = false, faded = 1 }) {
  const style = line
    ? { display: "inline-block", width: 18, height: 0, borderTop: `${dashed ? "2px dashed" : "3px solid"} ${color}`, verticalAlign: "middle" }
    : { display: "inline-block", width: 12, height: 12, borderRadius: 2, background: color, opacity: faded, verticalAlign: "middle" };
  return <span aria-hidden="true" style={style} />;
}

// Hover box for one bar: the range, the count, and its share of all values.
function BinTooltip({ active, payload, total }) {
  if (!active || !payload?.length) return null;
  const bin = payload.find((item) => item.dataKey === "count")?.payload;
  if (!bin) return null;
  return (
    <div style={{ background: "#fff", border: "1px solid #d1d5db", borderRadius: 6, padding: "6px 10px", fontSize: 13 }}>

// Picks about 6 round numbers between start and end (steps of 1, 2, 2.5 or 5 x 10^n).
function niceTicks(start, end, count = 6) {
  const rough = (end - start) / count;
  const power = 10 ** Math.floor(Math.log10(rough));
  const step = [1, 2, 2.5, 5, 10].map((m) => m * power).find((m) => m >= rough);

  const ticks = [];
  for (let t = first; t <= end + step * 1e-9; t += step) ticks.push(Number(t.toFixed(10)));
  return ticks;
}

Box Plot

Shows the five-number summary in one line: the box is Q1 to Q3 (its width is the IQR), the thick line is the median, the whiskers reach the furthest values that are not outliers, circles are outliers, and the orange diamond is the mean. It's plain SVG with a viewBox, so it needs no library and fits any screen or page.

src/dashboard-kit/BoxPlot.jsx

// BoxPlot.jsx: a horizontal box plot in plain SVG (no library needed).
//   box      = Q1 to Q3, the middle 50% (its width is the IQR)
//   line     = the median
//   whiskers = the smallest and largest values that are NOT outliers
//   dots     = outliers (beyond 1.5 x IQR past the box: Tukey's rule)
//   diamond  = the mean
//
// Use it:  <BoxPlot values={orderTotals} unit="$" />
import { cleanNumbers, describe } from "./stats.js";

export default function BoxPlot({ values, unit = "", decimals = 0, color = "#3987e5" }) {
  const data = cleanNumbers(values);
  if (data.length < 3) return null;
  const s = describe(data);

  // Whiskers stop at the last real value inside the fences.
  const inside = data.filter((v) => v >= s.fences.low && v <= s.fences.high);
  const whiskerLow = Math.min(...inside);
  const whiskerHigh = Math.max(...inside);

  // The SVG is 1000 units wide and stretches to fit its box (viewBox),
  // so it works at any screen size and on paper.
  const W = 1000;
  const pad = 40;
  const x = (v) => pad + ((v - s.min) / (s.max - s.min || 1)) * (W - pad * 2);
  const format = (n) => `${unit}${n.toLocaleString("en-US", { maximumFractionDigits: decimals })}`;

  return (
    <figure className="print-keep" style={{ margin: 0 }}>
      <svg viewBox={`0 0 ${W} 130`} width="100%" role="img" aria-label={`Box plot. Median ${format(s.median)}, middle 50% from ${format(s.q1)} to ${format(s.q3)}.`}>
        {/* whisker line */}
        <line x1={x(whiskerLow)} x2={x(whiskerHigh)} y1="50" y2="50" stroke="#6b7280" strokeWidth="2" />
        <line x1={x(whiskerLow)} x2={x(whiskerLow)} y1="35" y2="65" stroke="#6b7280" strokeWidth="2" />
        <line x1={x(whiskerHigh)} x2={x(whiskerHigh)} y1="35" y2="65" stroke="#6b7280" strokeWidth="2" />

        {/* the box: Q1 to Q3 */}
        <rect x={x(s.q1)} y="25" width={x(s.q3) - x(s.q1)} height="50" rx="4" fill={color} fillOpacity="0.25" stroke={color} strokeWidth="2" />

        {/* median line */}
        <line x1={x(s.median)} x2={x(s.median)} y1="25" y2="75" stroke="#111827" strokeWidth="3" />

        {/* mean diamond */}
        <path d={`M ${x(s.mean)} 40 l 10 10 l -10 10 l -10 -10 z`} fill="#eb6834" />

        {/* outliers */}
        {s.outliers.map((v, i) => (
          <circle key={i} cx={x(v)} cy="50" r="6" fill="none" stroke="#111827" strokeWidth="2" />
        ))}

        {/* labels under the plot */}
        <text x={x(s.q1)} y="100" textAnchor="middle" fontSize="20" fill="#374151">Q1 {format(s.q1)}</text>
        <text x={x(s.q3)} y="100" textAnchor="middle" fontSize="20" fill="#374151">Q3 {format(s.q3)}</text>
        <text x={x(s.min)} y="125" textAnchor="start" fontSize="18" fill="#6b7280">Min {format(s.min)}</text>
        <text x={x(s.max)} y="125" textAnchor="end" fontSize="18" fill="#6b7280">Max {format(s.max)}</text>
      </svg>
    </figure>
  );
}

Summary Table And Sentence

The numbers as a table, plus one sentence written by the code (no AI, so it's free and always matches the numbers). The sentence picks its words from the skewness and the quartiles.

src/dashboard-kit/SpreadSummary.jsx

// SpreadSummary.jsx: the key numbers as a table, plus one plain-English sentence.
// Prints well (tables never get cut in half thanks to print.css).
//
// Use it:  <SpreadSummary values={orderTotals} unit="$" decimals={2} />
import { cleanNumbers, describe } from "./stats.js";

export default function SpreadSummary({ values, unit = "", decimals = 0 }) {
  const data = cleanNumbers(values);
  if (data.length < 3) return null;
  const s = describe(data);
  const f = (n) => `${unit}${n.toLocaleString("en-US", { minimumFractionDigits: decimals, maximumFractionDigits: decimals })}`;

  const rows = [
    ["Count", s.count.toLocaleString("en-US") + (s.missing ? ` (${s.missing} missing left out)` : "")],
    ["Mean (average)", f(s.mean)],
    ["Median (middle value)", f(s.median)],
    ["Standard deviation", f(s.sd)],
    ["IQR (middle 50%)", `${f(s.iqr)}  (${f(s.q1)} to ${f(s.q3)})`],
    ["Range (all values)", `${f(s.range)}  (${f(s.min)} to ${f(s.max)})`],
    ["Skewness", s.skewness.toFixed(2)],
    ["Outliers (Tukey 1.5 x IQR)", s.outliers.length.toString()],
  ];

  return (
    <div className="print-keep">
      <table style={{ width: "100%", borderCollapse: "collapse", fontSize: 14 }}>
        <tbody>
          {rows.map(([name, value]) => (
            <tr key={name} style={{ borderBottom: "1px solid #e5e7eb" }}>
              <th scope="row" style={{ textAlign: "left", padding: "6px 8px", fontWeight: 600 }}>{name}</th>
              <td style={{ textAlign: "right", padding: "6px 8px", fontVariantNumeric: "tabular-nums" }}>{value}</td>
            </tr>
          ))}
        </tbody>
      </table>
      <p style={{ fontSize: 14 }}>{explainSpread(s, f)}</p>
    </div>
  );
}

// One sentence a business owner can read. No AI: the numbers pick the words.
export function explainSpread(s, f) {
  let shape;
  if (Math.abs(s.skewness) < 0.5) shape = "The values are fairly balanced around the middle";
  else if (s.skewness > 0) shape = `A few large values pull the average (${f(s.mean)}) above the typical value (${f(s.median)})`;
  else shape = `A few small values pull the average (${f(s.mean)}) below the typical value (${f(s.median)})`;
  const middle = `half of all values fall between ${f(s.q1)} and ${f(s.q3)}`;
  const extra = s.outliers.length ? `, and ${s.outliers.length} unusual value${s.outliers.length === 1 ? "" : "s"} stand${s.outliers.length === 1 ? "s" : ""} out` : "";
  return `${shape}; ${middle}${extra}.`;
}

src/charts/scale.js

Shared math and formatting. niceTicks picks round steps for the axis, such as $0, $500, $1K, instead of odd numbers.

// Math and formatting shared by the charts.

// Round axis ticks: niceTicks(0, 1834, 4) -> [0, 500, 1000, 1500, 2000]
export function niceTicks(min, max, count = 4) {
  if (max <= min) return [min, min + 1];
  const rough = (max - min) / count;
  const power = 10 ** Math.floor(Math.log10(rough));
  const step = [1, 2, 2.5, 5, 10].map((m) => m * power).find((candidate) => candidate >= rough) ?? 10 * power;
  const start = Math.floor(min / step) * step;
  const ticks = [];
  for (let value = start; value < max + step * 0.999; value += step) ticks.push(Number(value.toFixed(10)));
  return ticks;
}

// 1,284 / 12.9K / 4.2M
export function compactNumber(value) {
  return new Intl.NumberFormat("en-US", { notation: "compact", maximumFractionDigits: 1 }).format(value);
}

export function fullNumber(value) {
  return new Intl.NumberFormat("en-US").format(value);
}

export function money(value, { compact = false, cents = false } = {}) {
  return new Intl.NumberFormat("en-US", {
    style: "currency",
    currency: "USD",
    notation: compact ? "compact" : "standard",
    maximumFractionDigits: compact ? 1 : cents ? 2 : 0,
    minimumFractionDigits: cents && !compact ? 2 : 0,
  }).format(value);
}

export function shortDate(date) {
  return date.toLocaleDateString("en-US", { month: "short", day: "numeric" });
}

export function longDate(date) {
  return date.toLocaleDateString("en-US", { weekday: "short", month: "short", day: "numeric" });
}

Give it a list of dates and one or more lines. With two or more lines it adds a legend, so the lines are not told apart by color alone. The left and right arrow keys move through the days.

import {
  CartesianGrid,
  Legend,
  Line,
  LineChart as RechartsLineChart,
  Tooltip,
  XAxis,
  YAxis,
} from "recharts";
import { longDate, niceTicks, shortDate } from "./scale.js";

export default function LineChart({
  dates,
  series,
  formatValue,
  formatTick = formatValue,
  label,
}) {
  if (!dates.length || !series.length) {
    return <p>No data for this period.</p>;
  }

  // Recharts wants one row per day, with a property for each line.
  const rows = dates.map((_, index) => {
    const row = { day: index };

    for (const line of series) {
      row[line.key] = line.values[index];
    }
    return row;
  });

  // Clean axis steps ($0, $1K, $2K...) instead of whatever Recharts picks.
  // niceTicks is the same helper the old hand-made chart used.
  const highest = Math.max(1, ...series.flatMap((line) => line.values));
  const ticks = niceTicks(0, highest, 4);

  return (
    <RechartsLineChart
      responsive
      accessibilityLayer
      title={label}
      desc="Use the left and right arrow keys to explore each day."
      data={rows}
      style={{ width: "100%", height: 280 }}
      margin={{ top: 12, right: 24, bottom: 4, left: 0 }}
    >
      {/* vertical grid lines are distracting, so turn them off */}
      <CartesianGrid vertical={false} stroke="var(--grid)" />
      <XAxis
        dataKey="day"
        tickFormatter={(index) => shortDate(dates[index])}
        tick={{ fill: "var(--muted)", fontSize: 12 }}
        tickLine={false}
        tickMargin={8}
        minTickGap={18}
        interval="preserveStartEnd"
        axisLine={{ stroke: "var(--axis)" }}
      />
      <YAxis
        domain={[0, ticks[ticks.length - 1]]}
        ticks={ticks}
        width={60}
        tickFormatter={formatTick}
        tick={{ fill: "var(--muted)", fontSize: 12 }}
        tickLine={false}
        axisLine={false}
      />
      <Tooltip
        wrapperClassName="no-print"
        isAnimationActive={false}
        cursor={{ stroke: "var(--text-2)" }}
        labelFormatter={(index) => {
          const date = dates[index];
          return date ? longDate(date) : "";
        }}
        formatter={(value, name) => [formatValue(value), name]}
        separator=": "
        contentStyle={{
          backgroundColor: "var(--bg)",
          border: "1px solid var(--line)",
          borderRadius: "var(--radius)",
        }}
        labelStyle={{ color: "var(--muted)" }}
        itemStyle={{ color: "var(--text)" }}
      />
      {/* Two or more lines (admin dashboard): a legend names each color,
          so the lines aren't told apart by color alone. */}
      {series.length > 1 && (
        <Legend
          verticalAlign="top"
          formatter={(name) => <span style={{ color: "var(--text-2)" }}>{name}</span>}
        />
      )}
      {series.map((line) => (
        <Line
          key={line.key}
          dataKey={line.key}
          name={line.name}
          type="linear"
          stroke={line.color}
          strokeWidth={2}
          dot={false}
          activeDot={{ r: 4, stroke: "var(--surface)", strokeWidth: 2 }}
          isAnimationActive={false}
        />
      ))}
    </RechartsLineChart>
  );
}

Give it a list of items, each with a label and a value. Each bar shows its value at the end. The hover box shows the share of the total, or with showShare off, how far it is above or below the average.

import {
  Bar,
  BarChart as RechartsBarChart,
  LabelList,
  Tooltip,
  XAxis,
  YAxis,
} from "recharts";

export default function BarChart({
  items,
  formatValue,
  color = "var(--series-1)",
  label,
  showShare = true,
}) {
  if (!items.length) {
    return <p>No data for this period.</p>;
  }

  const total = items.reduce((sum, item) => sum + item.value, 0);
  const average = total / items.length;
  const highest = Math.max(...items.map((item) => item.value));
  const lowest = Math.min(...items.map((item) => item.value));

  const rows = items.map((item) => {
    const share = total ? Math.round((item.value / total) * 100) : 0;
    const difference = average
      ? Math.round(((item.value - average) / average) * 100)
      : 0;

    let comparison = "About the average";
    if (difference > 0) comparison = `${difference}% above the average`;
    if (difference < 0)
      comparison = `${Math.abs(difference)}% below the average`;

    let rank = "";

    if (highest !== lowest && item.value === highest) {
      rank = "Highest. ";
    }
    if (highest !== lowest && item.value === lowest) {
      rank = "Lowest. ";
    }

    return {
      ...item,
      detail: showShare ? `${share}% of the total` : `${rank}${comparison}`,
    };
  });

  return (
    <RechartsBarChart
      responsive
      accessibilityLayer
      title={label}
      desc="Use the left and right arrow keys to explore the bars."
      layout="vertical"
      data={rows}
      style={{ width: "100%", height: rows.length * 36 + 16 }}
      margin={{ top: 8, right: 72, bottom: 8, left: 0 }}
    >
      <XAxis type="number" domain={[0, "auto"]} hide />

      <YAxis
        type="category"
        dataKey="label"
        width={112}
        tick={{ fill: "var(--text-2)", fontSize: 12 }}
        tickLine={false}
        axisLine={{ stroke: "var(--axis)" }}
      />

      <Tooltip
        wrapperClassName="no-print"
        isAnimationActive={false}
        cursor={{ fill: "var(--surface-2)" }}
        content={({ active, payload }) => {
          const item = payload?.[0]?.payload;
          if (!active || !item) return null;

          return (
            <div
              className="chart-tooltip"
              style={{ position: "static" }}
              role="status"
              aria-atomic="true"
            >
              <p className="chart-tooltip__date">{item.label}</p>
              <p>
                <strong>{formatValue(item.value)}</strong>
              </p>
              <p>{item.detail}</p>
            </div>
          );
        }}
      />

      <Bar
        dataKey="value"
        fill={color}
        barSize={20}
        radius={[0, 4, 4, 0]}
        isAnimationActive={false}
      >
        <LabelList
          dataKey="value"
          position="right"
          offset={8}
          formatter={formatValue}
          fill="var(--text)"
          fontSize={12}
          fontWeight={700}
        />
      </Bar>
    </RechartsBarChart>
  );
}

// A chart with a title and a "Show table" switch. The table has the same
// numbers as the chart, for screen readers, printing and anyone who prefers rows.
import { useState } from "react";

export default function ChartCard({ title, subtitle, columns, rows, children, className = "" }) {
  const [showTable, setShowTable] = useState(false);

  return (
    <section className={`chart-card ${className}`}>
      <header className="chart-card__head">
        <div>
          <h3 className="chart-card__title">{title}</h3>
          {subtitle && <p className="chart-card__subtitle">{subtitle}</p>}
        </div>
        <button type="button" className="text-button chart-card__switch" aria-pressed={showTable} onClick={() => setShowTable((on) => !on)}>
          {showTable ? "Show chart" : "Show table"}
        </button>
      </header>

      {showTable ? (
        <div className="table-wrap">
          <table className="data-table">
            <caption className="visually-hidden">{title}</caption>
            <thead>
              <tr>{columns.map((column) => <th key={column} scope="col">{column}</th>)}</tr>
            </thead>
            <tbody>
              {rows.map((row) => (
                <tr key={row[0]}>
                  {row.map((cell, index) => (index === 0 ? <th key={index} scope="row">{cell}</th> : <td key={index}>{cell}</td>))}
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      ) : (
        children
      )}
      {/* Printed reports always include the table under the chart. */}
      {!showTable && (
        <div className="print-only table-wrap">
          <table className="data-table">
            {rows.length > 31 && <caption>The last 31 rows of {rows.length}</caption>}
            <thead>
              <tr>{columns.map((column) => <th key={column} scope="col">{column}</th>)}</tr>
            </thead>
            <tbody>
              {rows.slice(-31).map((row) => (
                <tr key={row[0]}>
                  {row.map((cell, index) => (index === 0 ? <th key={index} scope="row">{cell}</th> : <td key={index}>{cell}</td>))}
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}
    </section>
  );
}

src/charts/WhatHappened.jsx

The What happened box from my REV dashboard: a few plain-English sentences about the numbers. It goes first, above the charts, because it is the part a busy owner reads. In REV this was written straight into Dashboard.jsx. Here it is its own component, so it can go on any page.

You give it the sentences. In REV they were written by AI from the sample numbers and saved in the data file, so the demo costs nothing per click. On a client site the server writes new ones each day from the real numbers and sends them with the rest of the data.

// The "What happened" box: a few plain-English sentences about the numbers.
// It goes first on the dashboard, above the charts, because it is the part
// a busy owner actually reads.
//
// Use it:
//   <WhatHappened sentences={["Sales were $11,930 this week...", "..."]} note="Updated each morning." />
import { useId } from "react";

export default function WhatHappened({ sentences, title = "What happened", note }) {
  const titleId = useId();

  if (!sentences.length) return null;

  return (
    <section className="summary" aria-labelledby={titleId}>
      <h2 id={titleId} className="summary__title">
        {title}
      </h2>
      <ul className="summary__list">
        {sentences.map((sentence) => (
          <li key={sentence}>{sentence}</li>
        ))}
      </ul>
      {note && <p className="summary__note">{note}</p>}
    </section>
  );
}

src/sampleData.js (fake data for testing)

// Fake data for the demo. Seeded, so it is the same every time.
function seeded(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
const random = seeded(42);
// Box-Muller: two uniform numbers -> one normal number.
const normal = () => Math.sqrt(-2 * Math.log(1 - random())) * Math.cos(2 * Math.PI * random());

// 400 order totals, skewed right like real orders (most small, a few big).
export const orderTotals = Array.from({ length: 400 }, () => Math.round(Math.exp(2.3 + 0.35 * normal()) * 100) / 100);
orderTotals.push(48.5, 52, "NA", null); // two big catering orders + two missing values

export const dailySales = Array.from({ length: 31 }, (_, i) => ({ day: i + 1, sales: Math.round(1400 + i * 8 + 220 * normal()) }));
