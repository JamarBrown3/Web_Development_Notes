How To Use These

Ten small effects that make an avatar or photo feel alive without getting in the way. Effects 1 to 5 play on their own for under 2 seconds, then rest. Effects 6 to 10 only react when someone hovers over the photo or reaches it with the Tab key.

Open the demo page to see all ten on a dark and a light background.

Every effect uses the same markup

  • An outer .fx box that does not clip, so a frame or halo can sit outside the photo.
  • An inner .fx__clip wrapper that clips the photo to a circle or rounded rectangle.
  • The img with real alt text.
  • Hover effects go on a link, because only links and buttons can get Tab focus. Do not add tabindex to a plain photo just for an effect.
  • Only transform and opacity animate, so the browser can run them smoothly.

css/fx-base.css

Paste this once. Then add the CSS for each effect you want.

/* Shared base for every photo effect. Paste this once. */
.fx {
  --fx-size: 120px;       /* width of the photo: works from 40px to 400px */
  --fx-ratio: 1;          /* 1 = square or circle, 4 / 3 = landscape */
  --fx-radius: 50%;       /* 50% = circle, 16px = rounded rectangle */
  --fx-color: #5b8cff;    /* accent color for rings, lines and glows */
  --fx-speed: 12s;        /* one idle loop: about 1.7s of motion, then rest */
  --fx-loops: infinite;   /* how many times an idle effect plays */
  --fx-hover-speed: 300ms; /* how fast hover and focus effects react */
  --fx-focus: #2563eb;    /* focus ring: 3:1 on white and on #101826 */
  position: relative;
  display: inline-block;
  width: var(--fx-size);
  max-width: 100%;        /* shrinks to fit on a phone */
  aspect-ratio: var(--fx-ratio);
  border-radius: var(--fx-radius);
  vertical-align: middle;
  color: inherit;
  text-decoration: none;
}

/* The inner wrapper clips the photo. The outer box does not clip,
   so an effect can draw a frame or halo outside the photo. */
.fx__clip {
  position: relative;
  display: block;
  width: 100%;
  height: 100%;
  border-radius: inherit;
  overflow: hidden;
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.15);
}

.fx__img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

/* Effects are decoration only: they never catch clicks. */
.fx::before,
.fx::after,
.fx__clip::before,
.fx__clip::after {
  pointer-events: none;
}

/* A photo that is a link gets a clear focus ring for keyboard users. */
a.fx:focus-visible {
  outline: 3px solid var(--fx-focus);
  outline-offset: 6px;
}

/* Less motion: idle effects stop after three loops. */
.fx--limited {
  --fx-loops: 3;
}

/* The pause button adds this class to body. It stops every idle effect
   and puts it back in its resting look. */
.fx-paused .fx,
.fx-paused .fx *,
.fx-paused .fx::before,
.fx-paused .fx::after,
.fx-paused .fx *::before,
.fx-paused .fx *::after {
  animation: none !important;
}

Pro-Tip: If an effect does nothing, check the three class names first: fx on the outer box, fx__clip on the wrapper, and fx__img on the image. Every effect is built on those three, and one typo switches it off without any error.

A circle and a rounded rectangle

Change the size and shape on each photo with a style attribute. The same effect works from 40px to 400px.

<!DOCTYPE html>
<html lang="en">
<head>

  <title>A Circle And A Rounded Rectangle</title>

       with the CSS for this effect pasted under it. -->
  <link rel="stylesheet" href="css/fx-base.css">

  <!-- --fx-size makes this one small. With nothing else set, the shape is a circle. -->
  <span class="fx fx-glow" style="--fx-size: 48px">

      <img class="fx__img" src="images/jah.jpg" alt="Jah smiling in a blue jacket">
    </span>
  </span>

  <!-- --fx-ratio and --fx-radius turn the circle into a 4 by 3 rounded rectangle. -->
  <span class="fx fx-scan" style="--fx-ratio: 4 / 3; --fx-radius: 16px; --fx-size: 320px">
    <span class="fx__clip">
      <img class="fx__img" src="images/weather-app.png" alt="Screenshot of the Weather App home page">
    </span>
  </span>
</body>
</html>

The same thing in React

React accepts CSS variables in the style object as long as the name is in quotes.

// src/components/SmallGlowPhoto.jsx
// The image is imported, so Vite can find the file and give back its address.
import photo from "../assets/jah.jpg";

const SmallGlowPhoto = () => {
  return (
    // The name of a CSS variable has dashes in it, so it goes in quotes inside the style object.
    <span className="fx fx-glow" style={{ "--fx-size": "48px" }}>
      <span className="fx__clip">
        <img className="fx__img" src={photo} alt="Jah smiling in a blue jacket" />
      </span>
    </span>
  );
};

export default SmallGlowPhoto;

Pro-Tip: In React, a path typed as plain text, such as src="images/jah.jpg", only works for a file in the public folder. For an image inside src, import it at the top of the file the way this box does.

1 Breathing Glow Ring

A soft ring around the photo brightens and grows a little, then rests.

Type: Idle: plays on its own. Shape: made for circles.

Best used for: Avatars, a profile photo in a hero, an online status for a team member.

Breathing Glow Ring CSS

/* 1. Breathing Glow Ring */
.fx-glow::before {
  content: "";
  position: absolute;
  inset: calc(var(--fx-size) * -0.05);
  border-radius: inherit;
  /* The glow is drawn once. Only its opacity and size animate. */
  box-shadow:
    0 0 0 2px var(--fx-color),
    0 0 calc(var(--fx-size) * 0.12) var(--fx-color);
  opacity: 0.35;
  animation: fx-glow var(--fx-speed) ease-in-out var(--fx-loops);
}

/* Moves for the first 14% of the loop (1.7s of 12s), then rests. */
@keyframes fx-glow {
  0%, 14%, 100% { opacity: 0.35; transform: scale(1); }
  7%            { opacity: 0.9;  transform: scale(1.03); }
}

/* Still version: a steady ring with no breathing. */
@media (prefers-reduced-motion: reduce) {
  .fx-glow::before {
    animation: none;
    opacity: 0.6;
  }
}

Accessibility

  • Reduced motion: the ring stays on at a steady 60% and does not move.
  • Keyboard: nothing to do. The photo is not a link.
  • Screen readers: the ring is a pseudo-element, so only the alt text is read.
  • Flashing: one soft brightening every 12 seconds, far under 3 per second.

Knobs to change

--fx-colorRing and glow color
--fx-speedTime between breaths
opacity: 0.9 in the keyframesHow bright the breath gets. Keep it under 1.

2 Rotating Gradient Border

A colored gradient border makes one full turn, then holds still.

Type: Idle: plays on its own. Shape: made for circles and rounded rectangles.

Best used for: A featured avatar, a 'new team member' card, a creator profile.

Rotating Gradient Border CSS

/* 2. Rotating Gradient Border */
.fx-spin {
  --fx-border: max(2px, calc(var(--fx-size) * 0.03));
  --fx-color-2: #ff7ad9;
  padding: var(--fx-border);
  overflow: hidden;       /* clips the spinning square into a ring */
  isolation: isolate;     /* keeps the gradient behind the photo */
}

/* A big square of gradient spins behind the photo. Only the strip
   showing through the padding is visible. */
.fx-spin::before {
  content: "";
  position: absolute;
  inset: -100%;
  z-index: -1;
  background: conic-gradient(
    var(--fx-color),
    transparent 30%,
    var(--fx-color-2) 55%,
    transparent 80%,
    var(--fx-color)
  );
  animation: fx-spin var(--fx-speed) ease-in-out var(--fx-loops);
}

/* One turn in the first 14% of the loop, then rest. */
@keyframes fx-spin {
  0%         { transform: rotate(0deg); }
  14%, 100%  { transform: rotate(360deg); }
}

/* Still version: the gradient border stays, it just does not turn. */
@media (prefers-reduced-motion: reduce) {
  .fx-spin::before {
    animation: none;
  }
}

3 Soft Pulse Halo

One thin ring drifts out from the photo and fades away. It is drawn outside the photo without being cut off.

Type: Idle: plays on its own. Shape: made for circles.

Best used for: An 'available for work' avatar, a live or on-call status, a contact photo.

Soft Pulse Halo CSS

/* 3. Soft Pulse Halo */
/* Leave about 15% of the photo size as free space around it,
   because the halo grows outside the photo. */
.fx-halo::after {
  content: "";
  position: absolute;
  inset: 0;
  border-radius: inherit;
  border: max(1px, calc(var(--fx-size) * 0.015)) solid var(--fx-color);
  opacity: 0;
  animation: fx-halo var(--fx-speed) ease-out var(--fx-loops);
}

/* One ring grows and fades in the first 15% of the loop. */
@keyframes fx-halo {
  0%         { opacity: 0.7; transform: scale(1); }
  15%, 100%  { opacity: 0;   transform: scale(1.25); }
}

/* Still version: a faint steady ring, no movement. */
@media (prefers-reduced-motion: reduce) {
  .fx-halo::after {
    animation: none;
    opacity: 0.5;
    transform: scale(1.08);
  }
}

  • Keyboard: nothing to do. The photo is not a link.

  • The ring is drawn by the outer box, which does not clip, so it is never cut off.

4 Corner Glint

A small four-point sparkle grows and turns on the edge of the photo, then disappears.

Type: Idle: plays on its own. Shape: made for circles.

Best used for: A profile photo on a portfolio hero, an award winner, a featured testimonial.

Corner Glint CSS

/* 4. Corner Glint */
.fx-glint {
  --fx-glint-size: 22%;  /* sparkle size, as a share of the photo */
  --fx-glint-spot: 10%;  /* distance from the top right corner. Use 2% on a rectangle. */
}

.fx-glint::after {
  content: "";
  position: absolute;
  top: var(--fx-glint-spot);
  right: var(--fx-glint-spot);
  width: var(--fx-glint-size);
  aspect-ratio: 1;
  background: radial-gradient(circle, #ffffff 0 25%, #fff4c2 60%);
  /* A four-point star */
  clip-path: polygon(50% 0, 60% 40%, 100% 50%, 60% 60%, 50% 100%, 40% 60%, 0 50%, 40% 40%);
  opacity: 0;
  transform: scale(0) rotate(0deg);
  animation: fx-glint var(--fx-speed) ease-in-out var(--fx-loops);
}

/* Grows, turns and fades in the first 8% of the loop (about 1s). */
@keyframes fx-glint {
  0%, 8%, 100% { opacity: 0;   transform: scale(0) rotate(0deg); }
  4%           { opacity: 0.9; transform: scale(1) rotate(45deg); }
}

/* Reduced motion: no sparkle at all. */
@media (prefers-reduced-motion: reduce) {
  .fx-glint::after {
    display: none;
  }
}

5 Scan Line

A soft band of light slides down over the photo once, then rests.

Type: Idle: plays on its own. Shape: made for rounded rectangles.

Best used for: Project screenshots, tech portfolio cards, a 'case study' photo.

Scan Line CSS

/* 5. Scan Line */
/* The band lives inside the clip wrapper, so it never leaves the photo. */
.fx-scan .fx__clip::after {
  content: "";
  position: absolute;
  inset: 0 0 auto 0;
  height: 30%;
  background: linear-gradient(
    transparent,
    color-mix(in srgb, var(--fx-color) 35%, transparent),
    transparent
  );
  transform: translateY(-100%);
  animation: fx-scan var(--fx-speed) ease-in-out var(--fx-loops);
}

/* Top to bottom in the first 14% of the loop, then rest out of sight. */
@keyframes fx-scan {
  0%         { transform: translateY(-100%); }
  14%, 100%  { transform: translateY(340%); }
}

/* Reduced motion: no band at all. */
@media (prefers-reduced-motion: reduce) {
  .fx-scan .fx__clip::after {
    display: none;
  }
}

6 Tilt And Lift

The photo tips toward you and rises, and a shadow fades in under it.

Type: Hover and focus: reacts when someone points at it or tabs to it. Shape: made for rounded rectangles.

Best used for: Portfolio project cards, product images, blog post covers.

Tilt And Lift CSS

/* 6. Tilt And Lift */
.fx-tilt {
  --fx-tilt: 6deg;
  transform: perspective(600px) rotateX(0deg) rotateY(0deg);
  transition: transform var(--fx-hover-speed) ease-out;
}

/* The shadow is drawn once and only fades, which is cheaper than
   animating box-shadow. */
.fx-tilt::after {
  content: "";
  position: absolute;
  inset: 0;
  z-index: -1;
  border-radius: inherit;
  box-shadow: 0 18px 30px rgba(0, 0, 0, 0.35);
  opacity: 0;
  transition: opacity var(--fx-hover-speed) ease-out;
}

.fx-tilt:is(:hover, :focus-visible, :focus-within) {
  transform: perspective(600px) rotateX(var(--fx-tilt)) rotateY(calc(var(--fx-tilt) * -1)) translateY(-4px);
}

.fx-tilt:is(:hover, :focus-visible, :focus-within)::after {
  opacity: 1;
}

/* Reduced motion: no tilt. The shadow still fades in, which is not motion. */
@media (prefers-reduced-motion: reduce) {
  .fx-tilt,
  .fx-tilt:is(:hover, :focus-visible, :focus-within) {
    transform: none;
  }
}

<html lang="en">
<head>

  <meta name="viewport" content="width=device-width, initial-scale=1.0">

Pause button JavaScript

// js/pause-button.js
// Stops every idle effect on the page. aria-pressed tells screen
// readers whether the button is on.
const pauseButton = document.getElementById("pause-button");

pauseButton.addEventListener("click", () => {
  // toggle adds the class when it is missing and removes it when it is there.
  // It gives back true when the class is now on the body.
  const paused = document.body.classList.toggle("fx-paused");
  // setAttribute needs text, so true or false is turned into "true" or "false".
  pauseButton.setAttribute("aria-pressed", String(paused));
});

Pro-Tip: If nothing happens on a click, open the Console. "Cannot read properties of null" means the script ran before the button existed. Keep the script tag at the end of the body, or add defer to it.

Pause button in React

// src/components/PauseButton.jsx
import { useEffect, useState } from "react";

const PauseButton = () => {
  // paused is true or false. setPaused changes it and draws the button again.
  const [paused, setPaused] = useState(false);

  // Runs after the button is drawn, every time paused changes.
  // The body is outside React, so the class is added to it by hand here.
  useEffect(() => {
    document.body.classList.toggle("fx-paused", paused);
  }, [paused]);

  return (
    // aria-pressed tells screen readers whether the button is on.
    // Each click flips paused to the opposite value.
    <button type="button" aria-pressed={paused} onClick={() => setPaused(!paused)}>
      Pause all animations
    </button>
  );
};

export default PauseButton;

WCAG 2.2.2 In Plain Words

WCAG 2.2.2, Pause, Stop, Hide, says that anything that moves on its own for more than 5 seconds next to other content needs a way for the user to pause, stop or hide it. A pause button does this, and so does stopping the motion on its own before 5 seconds are up.

To use less motion, add the fx--limited class next to fx, so an idle effect plays three times and stops. See the first item under Things I Am Unsure About before relying on that alone.

Things I Am Unsure About

  • WCAG 2.2.2 and the 3-loop version: each burst of motion is under 2 seconds, but three 12-second loops cover about 36 seconds. A strict reading treats that as motion lasting more than 5 seconds, so the 3-loop version alone may not be enough. The pause button covers it either way.
  • Grayscale To Color uses mix-blend-mode: saturation. I tested it in Chromium only, not Safari or Firefox.
  • The Scan Line uses color-mix(), which needs a browser from 2023 or newer. Older browsers show no band, which is harmless.
  • I tested reduced motion by switching the reduced motion rules on in Chromium, not with the real setting on a phone or a Mac.
  • Tilt And Lift tips in one fixed direction. Following the mouse would need JavaScript, so I left it out.
  • Corner Glint at 40px is a 9px sparkle. It works, but it is hard to notice at that size.

Review Checklist

Check every new effect against this list before it goes on a client site.

  • It turns off, or becomes a still version, under prefers-reduced-motion.
  • Nothing flashes more than 3 times in one second, and brightness changes are soft.
  • An idle loop moves for under about 2 seconds, then rests, and the page has a way to pause it.
  • A hover effect also works on Tab focus, and the focus ring has 3:1 contrast with the page.
  • Hover never hides or replaces information, such as the color of a product.
  • Pseudo-elements have pointer-events: none, and no text is placed inside the effect.
  • The image has real alt text, or alt="" only when the same words are right next to it.
  • Overlays do not make text near or on the photo hard to read.
  • Only transform and opacity animate. Anything else has a reason written in a comment.
  • It looks right at 40px and at 400px, on a circle and on a rounded rectangle.
  • It looks right on a dark page and a light page.
  • Effects that draw outside the photo have room around them, so nothing gets cut off.
